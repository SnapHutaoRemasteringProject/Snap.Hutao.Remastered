## 接手先做什么
1. 在独立数据目录启动原生应用，先验证向导 → 主窗口 → 页面导航 → 退出；记录第一处实际失败并修复。
2. 验证旧库升级、成就/抽卡导入导出、背包和养成。数据库查询继续在 SQL 筛选，不改成全表内存过滤。
3. 补齐当前 AI 会话、网络响应和元数据的 JSON 契约；再处理实际触发的第三方 AOT 问题。
4. 最后验收安装包和升级；未运行的路径不计通过。

## 上游依赖怎么处理
当前使用 CsWinRT 2.3.1，先把现有原生应用跑通，不以升级 3.0 为前提。
要迁移 3.0，先看 [已验证数据和 issue 交接](cswinrt3-assessment.md)，不要把还原没报错当成适配完成。
不是“八个包都缺 WinMD”，也不是所有包都要重写原生代码。
